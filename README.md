# 갤창랭킹 (dcrank)

디시인사이드 특정 갤러리에서 **날짜 범위** 안의 **글 / 댓글 / 글+댓글**을 모아 작성자별 순위를 내는 도구.
갤러리 ID와 기간을 넣고 버튼 한 번 누르면 끝.

## 실행

- **Windows**: `run.bat` 더블클릭
- **macOS / Linux**: `./run.sh`

처음 실행할 때 가상환경을 만들고 패키지를 설치한 뒤, 브라우저에 `http://127.0.0.1:5000`이 열린다.
(Python 3.10 이상 필요)

1. 갤러리 ID(`programming`) 또는 주소(일반·마이너·미니 갤 모두 가능)를 입력
2. 기간 선택 (오늘 / 어제 / 최근 7일 / 최근 30일 / 지난달 바로가기)
3. 글 · 댓글 · 글+댓글 중 선택 → **랭킹 뽑기**

결과 화면에서 합계/글/댓글 기준 정렬, 유동 합치기, CSV(엑셀용) · 원본 JSON 다운로드가 된다.
수집 결과는 `output/` 폴더에도 자동 저장된다.

### 명령줄

```bash
./run.sh crawl programming 2026-09-01 2026-09-30 --mode both --top 30
./run.sh crawl "https://gall.dcinside.com/mgallery/board/lists/?id=github" 2026-09-24 2026-09-30 --mode posts
```

옵션: `--mode posts|comments|both`, `--sort total|posts|comments`, `--merge-ip`, `--delay 1`, `--max-pages 300`, `--out output`

## 집계 기준

| 구분 | 기준 |
|---|---|
| 고닉 / 반고닉 | 식별코드(아이디) 단위로 합산 |
| 유동 | `닉네임(IP 앞자리)` 단위. "유동 하나로 합치기"를 켜면 전부 한 줄로 |
| 제외 | 공지 · 설문 · AD 행, 댓글돌이, 삭제된 댓글 |
| 댓글 | **기간 안에 작성된 글**에 달린 댓글 중 **기간 안에 작성된 것**만 셈. 기간 이전 글에 기간 중 달린 댓글은 빠진다 (그걸 다 잡으려면 갤 전체를 훑어야 해서) |

## 사이트 부담 / 규칙 준수

- **robots.txt 준수**: 실행 시 `gall.dcinside.com/robots.txt`를 읽고, 막힌 갤러리(목록)면 시작하지 않고 막힌 글은 댓글을 가져오지 않는다.
  (표준 `urllib.robotparser`는 앞에 나온 규칙을 적용해서 디시 robots.txt를 "전부 허용"으로 잘못 읽는다. 그래서 RFC 9309대로 가장 긴 규칙을 적용하는 파서를 따로 넣었다.)
- **요청은 하나씩, 최소 1초 간격** (기본 1~1.3초). 동시 요청이나 병렬 작업은 없고, 웹 UI도 한 번에 작업 하나만 돌린다.
- **403이면 즉시 중단**하고, 429/5xx는 `Retry-After`만큼 쉬었다가 몇 번 재시도한 뒤 중단한다. 프록시 교체·캡차 우회·로그인 같은 회피는 하지 않는다.
- 도구 이름을 그대로 밝히는 User-Agent(`dcrank/x.y`)를 쓴다.
- 기간 시작 지점은 이분 탐색으로 찾아서 앞쪽 페이지를 통째로 읽지 않고, 목록은 한 쪽에 100개씩 받아 요청 수를 줄인다.
- 글 목록 페이지 상한(기본 300쪽 = 3만 글)이 있어서 큰 갤에서 실수로 몇 시간씩 긁지 않는다. 상한에 걸리면 결과에 표시된다.

예상 소요: 목록 100글당 요청 1회 + **댓글 달린 글 1개당 요청 1회**. 시간은 대부분 댓글 수집에 든다
(예: 기간 내 댓글 달린 글 1,000개면 약 20분). 진행 중에 남은 시간과 중간 순위가 계속 표시된다.

**댓글 캐시**: 글별 댓글을 `output/cache.sqlite3`에 저장하고, 다음 실행 때 목록의 댓글 수가 같은 글은 다시 받지 않는다.
"최근 3일"을 매일 돌리면 겹치는 이틀치는 거의 요청 없이 끝난다. 캐시를 지우려면 그 파일을 삭제.

이용약관은 직접 확인할 것. 개인 통계 용도로 적당히 쓰고, 수집한 닉네임·IP 앞자리는 다른 데 퍼뜨리지 말자.

## 구조

```
dcrank/
  robots.py    robots.txt 파서 (가장 긴 규칙 우선)
  client.py    요청 간격·재시도·차단 처리
  parser.py    갤러리 주소 해석, 목록 HTML / 댓글 JSON 파싱
  crawler.py   시작 페이지 탐색 → 글 수집 → 댓글 수집
  ranking.py   집계, CSV/JSON
  web.py       로컬 웹 UI (Flask)
tests/         가짜 응답으로 돌리는 테스트 (실제 사이트에 요청하지 않음)
```

테스트: `.venv/bin/pip install pytest && .venv/bin/python -m pytest`
